# Benchmarks

Performance measurements, bottleneck analyses, and optimization studies. Each document keeps its benchmark data in a folder of the same name.

Benchmarks are historical records in the sense that a benchmark measures a point in time. They are never updated after the measurement. A new benchmark run gets a new document or a new dated folder. Before/after numbers that later work compares against stay here permanently.

## Adding a Benchmark

1. Write the benchmark document in this folder (e.g. `request-latency.md`).
2. Create a folder of the same name (`request-latency/`) containing the raw benchmark data (e.g. `benchmark.json`).
3. The document covers: what was measured, how, the results, and the analysis of where the time goes.
4. Add a row to the table above.
5. Add a row to the Benchmarks table in `.agents/README.md`.
